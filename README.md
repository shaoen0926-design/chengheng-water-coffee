# 澄衡-水咖紀錄

深色科技風的喝水與咖啡紀錄工具，公開版 v1.1.0。透過 GitHub Pages 發布，原始碼採純 HTML、CSS 與 JavaScript。

- [開啟澄衡-水咖紀錄](https://shaoen0926-design.github.io/chengheng-water-coffee/)
- [GitHub 原始碼與版本](https://github.com/shaoen0926-design/chengheng-water-coffee)
- [更新紀錄](CHANGELOG.md)

## 開啟與使用

使用上方網站，或下載完整專案後以瀏覽器開啟 [index.html](index.html)。不需安裝套件或登入；本機 HTML 可離線使用。首次使用從空白紀錄開始，不會放入示範資料。

手機可將網站加入主畫面。網站已提供 iPhone／iPad 的 Apple Touch Icon 與 Android manifest 圖示，名稱統一為「澄衡-水咖紀錄」。主畫面以獨立視窗開啟；本版未提供網站離線快取，從線上入口重新開啟仍需網路。

- 點容量即可記錄喝水；點飲品即可記錄一杯咖啡。手機底部另有固定的快速登記按鈕。
- 「自訂 / 補登」可輸入容量、名稱、日期與時間，拒絕未來的飲用時間。
- 水可以用 `+10 / +30 / +50 ml` 少量累加；手機底部另有「小口登記」。
- 咖啡「分次喝」會依實喝量 ÷ 整杯容量累計杯數，並顯示咖啡總 ml，獨立於喝水量；不換算咖啡因。
- 「目標與資料」調整喝水目標與咖啡杯數上限。初始值為 2,000 ml 與 2 杯，只是可修改的紀錄起點，並非健康建議。
- 喝水達標會顯示鼓勵訊息與動畫；超出咖啡上限會以琥珀轉暖紅的提示呈現，仍可如實記錄。
- 近七天圖表可點選日期查看紀錄；「全部紀錄」顯示最近 200 筆，備份包含全部資料。
- 新增後可在提示列撤銷；刪除紀錄後可在提示列復原。若在紀錄視窗內刪除，先關閉視窗即可操作提示列。

## 小口與分次喝

每次只登記**這次新喝下的量**，不用每一口都操作，也可以隔一段時間合併記錄。快捷容量是便於選擇的數字，不代表每個人一口的實際大小。

- 水：10 ml + 30 ml + 50 ml，當日累計增加 90 ml。也可用瓶內剩餘量估計，例如 500 ml 喝剩 350 ml，就登記 150 ml。
- 咖啡：整杯 240 ml、這次喝 30 ml，累加 0.125 杯；登記 8 次後共 240 ml、1 杯。
- 不同杯型各自換算：濃縮整杯 60 ml，喝 30 ml 算 0.5 杯；拿鐵整杯 360 ml，喝 180 ml 也算 0.5 杯。杯數是個人紀錄單位，不代表相同咖啡因。

「分次喝」預設登記 30 ml，整杯容量及名稱沿用最近的咖啡紀錄。換新飲品時調整整杯容量；同一杯分次喝時，整杯容量保持不變。每次實喝量不得大於整杯容量，多杯請分別登記。已分次記錄的同一份飲品，不再點一次整杯按鈕，以免重複累計。

杯數顯示到小數第 4 位，累加採原始容量比例，避免每筆顯示四捨五入造成累計誤差。咖啡上限、歷史趨勢及平衡日成就使用相同的分次累計結果。

## 成就與日期

1. **第一口**：登記第一筆喝水。
2. **補水達人**：任一天達到當日喝水目標。
3. **穩定節奏**：連續三個日曆日達到各天的喝水目標。
4. **平衡日**：已結束的日期喝水達標，且已登記咖啡未超過當日上限。當天尚未結束不會先頒發。

日期與時間固定採 `Asia/Taipei`，跨午夜會更新今日儀表板；未記錄日期不推定為達標。成就依現存紀錄重新計算，撤銷或刪除紀錄可能使成就重新鎖定。

第一次登記某日期時，會保存當時的目標快照。修改目標套用到今天及往後，過去已有紀錄的日期維持原目標。補登尚未有紀錄的歷史日期會使用目前設定。

## 資料與備份

所有紀錄保存在此瀏覽器的 `localStorage`，鍵名沿用 `qinheng-water-coffee-v1`，以相容初稿資料。沒有外部程式、字型、追蹤或雲端上傳。

v1.1.0 資料與新備份使用格式版本 2，為咖啡加上 `cupMl` 整杯容量。可讀取格式版本 1 的舊紀錄與備份，並將原本每筆咖啡保留為一整杯；既有水量、目標、日期及識別碼不變。新備份需由 v1.1.0 或更新版本還原。

「目標與資料」可以匯出 JSON 備份，或還原同格式備份。還原前會檢查格式、容量、日期與重複識別碼，顯示紀錄筆數並要求確認；確認後取代全部現有資料。取消或讀取失敗會保留目前資料。

本機初稿與 GitHub Pages 是不同的儲存來源；搬移既有紀錄時，先在原入口匯出備份，再到正式網站還原。

移動 HTML 檔案、更換瀏覽器／裝置、使用不同本機網址或清除網站資料，都可能改變可讀到的紀錄。請保持同一開啟方式，並定期備份。若瀏覽器無法儲存，畫面會明確提示暫存狀態；關閉前應先匯出。

## 驗證

已用 Chrome 與獨立的 Playwright 測試環境檢查：

- 快速新增、撤銷、歷史刪除與復原，以及重新載入後的資料保存。
- 自訂與補登、未來時間拒絕、目標變更及歷史目標快照。
- 咖啡獨立計數、超過上限、四項成就、連續達標與台北跨日更新。
- 八次小口合成一杯、不同杯型、分數杯上限、撤銷、舊資料移轉，以及部分飲用對過去成就的影響。
- 備份匯出／還原、取消還原、拒絕重複紀錄與保留現有資料。
- 320、390、768、1,024、1,440 px 螢幕寬度，以及手機快速操作。

測試腳本為 [tests/browser-check.cjs](tests/browser-check.cjs) 與 [tests/sips-check.cjs](tests/sips-check.cjs)。啟動本機 HTTP server 後，以安裝 Playwright 的環境執行：

```sh
python3 -m http.server 4326 --bind 127.0.0.1
# 另一個終端機執行；PLAYWRIGHT_MODULE 可指定已安裝模組的路徑。
node tests/browser-check.cjs
node tests/sips-check.cjs
```

測試截圖保存在 `verification/`，其中數字為隔離測試資料，不會寫入使用者的瀏覽器紀錄。

## 版本範圍

本版提供手動記錄與視覺進度，尚未提供背景推播、裝置同步、自動飲水偵測或咖啡因估算。預設咖啡容量可在自訂紀錄調整。本版最多保存 50,000 筆紀錄；實際上限亦受瀏覽器儲存配額影響。
